TASK: put this folder on GitHub, in a new repo called workshop-demo, without the secret key.
Then make a new folder with a note in it, and upload it as a second commit.
Type each command on its own: copy one line at a time.

1. Open Git Bash / Terminal (its icon is on the desktop) and log in with your GitHub token.
   (No token? Press "Use without GitHub" to practise on the Mini laptop's pretend GitHub.)

2. Go into this folder:
     cd ~/hehehe

3. Look at everything, hidden files too:
     ls -a
   See .env? It holds a secret key (a fake one). It must never reach GitHub.

4. Turn the folder into a Git repo:
     git init

5. Tell Git who you are (if you have not yet), with your own name and email:
     git config --global user.name "Your Name"
     git config --global user.email "you@example.com"

6. Ask Git what it sees:
     git status
   Uh oh: .env is in the list, so git add . would save it.

7. Make Git ignore it: a .gitignore file with .env in it:
     echo ".env" > .gitignore

8. Ask again:
     git status
   .env is gone from the list, and .gitignore is new.

9. Stage everything and save it (your first commit):
     git add .
     git commit -m "Add memes"

10. Make the new repo workshop-demo on GitHub, connect this folder to it, and upload. Pick one way:
   All in one go:
     gh repo create workshop-demo --public --source=. --remote=origin --push
   Or the long way, one step at a time (same result):
     a. Make the empty repo on GitHub:
          gh repo create workshop-demo --public
     b. Connect this folder to it. gh now shows a line that starts with  git remote add origin
        (it already has your GitHub name in it). Copy that line, paste it, press Enter.
     c. Upload your first commit:
          git push -u origin main

11. Check where it is connected:
     git remote -v
   You see your repo's link (with your GitHub name in it) twice:
   (fetch) is where git fetch and git pull download from, (push) is where git push uploads to.

12. Now make a new folder with bash, and put a note in it:
     mkdir notes
     echo "my favourite meme is star-forks" > notes/fav.txt
     ls notes
   (Git only uploads folders that have a file inside. An empty folder never reaches GitHub.)

13. Save it as a second commit and upload it:
     git add notes
     git commit -m "Add my favourite meme"
     git push

Done when workshop-demo on GitHub has 2 commits, the 5 memes, README.md, task.txt, .gitignore and notes/fav.txt, and NOT .env.
